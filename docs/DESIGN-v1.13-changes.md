# 우리집 대피지도 변경 명세 v1.13

`inst.md`의 가구 크기·분류·주인공 중복 지시와 문·현관 크기 반복 요청을 실제 조작 기준으로 다시 정의한다. 이 문서는 v1.12보다 뒤의 결정이며 충돌하면 v1.13이 이긴다.

## 1. 완료 판정

코드에 크기 값이 있는 것만으로 완료로 보지 않는다. 어린이가 도면에서 대상을 고른 뒤 화면에 나타나는 48px 이상의 단추로 값을 바꾸고, 2D 도면·저장자료·3D 리플레이에서 같은 결과를 확인할 수 있어야 한다.

## 2. 가구 크기

- 침대·소파·책상·옷장·책장·식탁·냉장고·티브이·싱크대·컴퓨터·세탁기·건조기·가스불은 서로 다른 기본 크기를 쓴다.
- 모든 가구 정의에는 종류별 `minSize`와 `maxSize`가 있다. 선택하면 `가로 줄이기/늘리기`, `세로 줄이기/늘리기`가 바로 보인다.
- 조절 결과는 `PointBlock.size`에 저장한다. 선택 윤곽·누름 판정·끌기·도면 경계·2D 그림·3D 가구가 같은 크기를 쓴다.
- 도면 밖으로 나가는 크기는 거부하고 이유를 한 줄로 알려 준다.

## 3. 가구 분류

- 침대와 가스불은 모두 `가구` 갈래에 둔다.
- 예전 저장자료와 시작 평면에서 `kind: hazard`였던 가스불은 읽을 때 `kind: furniture`로 바꾼다.
- 가스불의 화재 발원 가중치와 안전 판정은 `subKind: gas_range`로 계속 유지한다. 화면 분류가 바뀌어도 위험성이 사라지지 않는다.

## 4. 문과 현관 크기

- 여닫이문·현관문·실내문·창은 1~3칸, 미닫이문·미닫이창은 1~6칸 안에서 줄이고 늘린다.
- 숫자 선택만 숨겨 두지 않는다. 대상을 고르면 `줄이기`, 현재 칸 수, `늘리기`를 한 줄에 표시한다.
- 현관문은 조작부 제목을 `현관문 너비`로 표시한다.
- 현관 공간을 고르면 도면의 8방향 손잡이와 상단 `가로·세로` 단추가 함께 나타난다. 벽 없는 현관 구역도 같은 단추로 범위를 다시 지정할 수 있다.

## 5. 주인공 한 명 원칙

- 도면에는 `my_spot`이 최대 한 개만 남는다. 새로 정하면 기존 표시를 옮긴다.
- 게임을 시작하기 직전에 저장자료를 다시 정규화한다.
- 2D 연습에서는 고정 `my_spot`을 숨기고 움직이는 플레이어만 그린다.
- 3D 리플레이 입력에서는 모든 `my_spot` 블록을 제거하고, 기록된 위치를 따르는 `Avatar3D` 한 명만 만든다. 1인칭 손은 같은 한 명의 신체 표현이다.

## 6. 검증

- 콘텐츠 검증은 모든 가구의 기본·최소·최대 크기 순서와 가스불 분류를 검사한다.
- 로직 검증은 이전 가스불 자료 이동, 내 위치 중복 제거, 가구 크기 허용·거부, 현관 크기 변경을 검사한다.
- Chromium은 침대 가로·세로 조절과 저장, 현관 공간 조절, 여닫이문·현관문 너비 조절, 게임·3D 리플레이의 주인공 한 명을 실제로 누른다.
- 1024×768, 1440×900, 1920×1080 화면을 찍어 조작부가 도면을 가리거나 화면 밖으로 밀려나지 않는지 확인한다.

## 7. 음성

이번 변경은 실제 캐릭터 발화 문장을 추가·수정·삭제하지 않는다. `VOICE-SCRIPT.md`와 MP3 176개는 바꾸지 않으며 ElevenLabs 자동화도 실행하지 않는다.

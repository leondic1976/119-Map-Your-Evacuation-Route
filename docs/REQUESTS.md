# 요청 관리대장

이용자가 말한 것을 하나도 흘리지 않기 위한 문서다. **새 지시를 받으면 먼저 여기에 적고**,
끝내면 상태를 고친다. 미이행이 남아 있으면 보고할 때 그 사실을 함께 말한다.

- **함** — 코드에 들어갔고 검증을 통과했다
- **하는 중** — 손대고 있다
- **막힘** — 이용자가 무언가를 해 주어야 진행된다
- **대기** — 아직 시작하지 않았다

설계서 반영이 필요한 것은 `docs/DESIGN-v1.x-changes.md` 에 먼저 적는다 (작업지침 §9).

### 133번 메모 — 어린이 시험에서 찾은 불편 (#134 에서 고침)

판 2.8.0 공개 주소를 Chromium 자동 조작으로 시험했다. 실제 어린이·손가락·소리 품질은 확인하지 못했고, iPad Safari 는 돌리지 않았다.

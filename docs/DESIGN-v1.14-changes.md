# 우리집 대피지도 변경 명세 v1.14

배포된 3D 리플레이에서 1인칭 양팔이 서로 떨어진 세로 인형 두 개처럼 보이고, 숨긴 전신 아바타까지 장면에 함께 생성되는 문제를 바로잡는다. 이 문서는 v1.13보다 뒤의 결정이며 충돌하면 v1.14가 이긴다.

## 1. 한 시점에 하나의 주인공 표현

- 1인칭에서는 카메라에 붙은 `FirstPersonHands3D` 하나만 생성한다.
- 뒤에서 보기와 집 전체에서는 `Avatar3D` 하나만 생성한다.
- 전신 아바타를 `visible=false`로 숨겨 함께 두지 않는다. JSX 단계에서 둘 중 하나만 장면에 넣는다.
- 리플레이 최상위에는 현재 표현을 `first-person-body` 또는 `full-avatar`로 기록해 실제 브라우저 검증이 시점별 단일 표현을 확인한다.

## 2. 1인칭 몸 모양

- 양팔 사이에 고른 옷 색의 어깨·상체를 연결해 한 사람의 몸으로 읽히게 한다.
- 팔은 화면 아래에서 중앙을 향해 비스듬히 뻗고, 손과 소매를 구분한다. 세로로 선 작은 사람 두 명처럼 보이는 배치는 금지한다.
- 양팔은 한 `player-*` 그룹의 신체 부위이며 각각 별도 플레이어 이름을 갖지 않는다.

## 3. 검증

- 정적 점검은 `Scene`이 1인칭 몸과 전신 아바타를 배타적으로 렌더링하는지 검사한다.
- Chromium은 1인칭·뒤에서·집 전체를 차례로 눌러 현재 플레이어 표현 값이 매번 하나인지 확인한다.
- 1024×768, 1440×900, 1920×1080에서 1인칭과 뒤에서 보기 화면을 캡처해 눈으로도 중복이 없는지 확인한다.

## 4. 음성

실제 캐릭터 발화는 바뀌지 않는다. `VOICE-SCRIPT.md`와 Juwonmom MP3는 수정하거나 재생성하지 않는다.

# 우리집 대피지도 변경 명세 v1.16

작성일: 2026-09-01

대상: 3D 리플레이 어린이 캐릭터 체형

우선순위: 이 문서가 v1.15보다 뒤의 결정이며 충돌하면 v1.16이 이긴다.

## 1. 문제

3D 리플레이의 내 캐릭터가 문·가구와 비교해 너무 크고 몸통과 다리가 길어 성인처럼 보인다. 앞서 선택한 캐릭터 특징은 유지하면서 초등학생 체형으로 바로잡는다.

## 2. 체형 기준

- 바닥부터 머리끝까지의 모델 높이를 기존보다 15~20% 낮춘다.
- 다리와 몸통은 짧게, 머리는 전체 키에 비해 조금 크게 만든다.
- 어깨 폭과 팔 길이를 함께 줄여 팔이 무릎 아래로 내려오지 않게 한다.
- 발은 바닥에 닿고 그림자와 이름표가 새 높이를 따른다.
- 걷기·몸 낮추기 동작에서 발이 바닥 아래로 꺼지거나 머리가 천장을 뚫지 않는다.
- 1인칭 눈높이와 손·팔 위치도 같은 어린이 체형을 기준으로 낮춘다.

## 3. 검증

- 절차형 캐릭터 부위의 최대 높이와 다리·몸통·머리 비율을 소스 검사로 고정한다.
- 1024×768, 1440×900, 1920×1080의 따라가기 시점에서 문과 비교해 어린이 키로 보이는지 확인한다.
- 1인칭에서 눈높이와 두 팔이 캔버스 밖으로 밀리지 않는지 확인한다.

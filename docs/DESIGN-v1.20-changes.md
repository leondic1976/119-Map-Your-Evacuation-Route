# 설계 변경 명세 v1.20 — 웹 실행을 첫째 갈래로

v1.19 다음이다. 어긋나면 이 문서가 이긴다 (작업지침 §10).

## 1. 배경 — 요청 대장 #92 「웹으로도 실행되게 조치」

v1.18 이 제품을 「내려받아 설치해 쓰는 것」으로 세웠다. 그 뒤로 설치 안내(`/download/`)는 세 갈래
(브라우저에 설치 · 오프라인 꾸러미 · 윈도우 설치 파일)만 말하고, **설치하지 않고 웹 주소를 열어 쓰는 길**은
어디에도 적혀 있지 않았다. 소개 화면 단추도 「PC에 설치하기」다. 웹은 늘 돌고 있었지만 안내가 설치만 말하니
「웹으로는 안 되는 것」처럼 읽힌다.

실제 확인 — 공개 주소에서 이용자 PC 의 Chrome 156(Intel UHD 770)으로 소개 → 이름표 → 편집(확대 묶음·전체 화면)
→ 게임 → 결과 → 3D 리플레이(고급 → 높음 자동 하향, 집 전체·1인칭)까지 돌았고 페이지 오류는 0건이었다.
새 프로필로 처음 들어오는 흐름(온보딩 포함)도 헤드리스 Chromium 에서 완주했다. 다만 웹에서만 드러나는 작은 흠 둘이 있었다.

| 흠 | 원인 | 결과 |
|---|---|---|
| 웹 HTML 에 `rel="icon"` 이 없다 | `metadata.icons` 에 `apple` 만 적어 `app/icon.svg` 규약이 묻혔다 | 브라우저가 사이트 뿌리 `/favicon.ico` 를 찾아 **매 방문 404** · 탭 아이콘이 빈다 |
| 오프라인 HTML 에 `/icon.svg` 절대 링크가 남는다 | 오프라인 빌드는 `icons` 를 비워 규약 링크가 그대로 들어간다 | `file://` 과 다른 웹 서버에서 404 |

## 2. 결정

### 2.1 설치 안내 첫 줄에 「웹에서 바로 쓰기」 (v1.18 §6 보강)

- 카드 세 장 **위에** 띠 하나를 둔다: 「설치하지 않아도 돼」 · 「이 주소를 열면 바로 그릴 수 있어. 한 번 열어 두면
  다음부터는 인터넷이 없어도 열려.」 · 실제 주소 · 단추 「웹에서 바로 쓰기」(`data-coach="kids-download-web"`, 첫 화면으로).
- 주소는 **하드코딩하지 않는다.** 지금 열린 페이지 주소에 기준 경로를 더해 만든다(`data-web-address`). 그래야 다른 서버에
  올려도 그 서버 주소가 나온다. 화면에 github.com 주소를 박지 않는다는 규칙(v1.18 §5.3)과도 맞다.
- 머리글은 「웹에서 바로 쓰거나, PC에 설치하자」로 바꾼다. 카드 세 장, `선생님·보호자께`, 바깥 링크 0건, 48px 규칙은 그대로다.
- 소개 화면의 「PC에 설치하기」 단추는 그대로 둔다 — 소개 화면 자체가 웹 실행이다.

### 2.2 탭 아이콘을 명시한다

- 웹: `metadata.icons.icon = <기준 경로>/icon.svg` 와 `apple` 을 함께 적는다. `/favicon.ico` 탐색이 사라진다.
- 오프라인: 같은 SVG(`src/app/icon.svg` 를 빌드 때 읽는다)를 **data URI** 로 넣는다(+0.7KB). 오프라인 HTML 에
  뿌리 절대 경로(`href="/…"`·`src="/…"`)를 남기지 않는다 — `file://` 에서도, 어느 서버의 어느 폴더에서도 404 가 없다.

### 2.3 꾸러미는 웹 서버에 올려도 된다 (v1.18 §5.2 보강)

- 꾸러미 폴더(`우리집 대피지도/`)를 통째로 웹 서버의 어느 경로에 올려도 `home-escape-map.html` 이 돈다. 모든 경로가
  상대 경로이고, 서비스 워커는 등록하지 않으며, 바깥 요청은 0건이다. 로컬 HTTP 서버에서 소개 → 이름표 → 온보딩 → 편집을
  완주하고 음성이 `voice/` 상대 경로로 응답하는 것을 확인했다.
- 자체 호스팅에서 브라우저 설치(서비스 워커·매니페스트)까지 쓰려면 `BASE_PATH=/경로 npm run build` 로 만든 `out/` 을 올린다.
- 읽어주세요.txt 와 README 에 적는다.

### 2.4 하지 않는 것

- 1024px 미만 PC 안내(#29)와 「Chrome·Edge·Whale 최신 2개 판」 요건은 그대로다. 옛 브라우저용 대체 CSS 를 넣지 않는다.
- 저장소 공개 범위·Pages 설정은 바꾸지 않는다(작업지침 §1).

## 3. 검증

- 배포 전 점검(+1): `layout.tsx` 가 아이콘을 명시하고, 웹 HTML(`out/index.html`)에 `rel="icon"` 이 있으며,
  오프라인 HTML 에 뿌리 절대 경로가 0건이고 아이콘이 data URI 다.
- Chromium(기존 설치 안내 시나리오 확장, 수는 42 그대로): 웹 바로 쓰기 단추가 첫 화면 주소를 가리키고, 표시된 주소가
  지금 서버의 주소와 같으며, 「설치하지 않아도 돼」·「웹에서 바로 쓰기」 글이 있다. 바깥 링크 0건·48px·가로 넘침 검사는 그대로 통과한다.
- 3D 리플레이 두 시나리오는 소프트웨어 GL(CI 러너)에서 한 컷에 몇 초씩 걸려 Playwright 의 30초 기본 제한에 걸릴 수 있다.
  앱이 아니라 소프트웨어 그리기의 느림이므로 그 두 시나리오만 조작 제한 시간을 120초로 준다(`slowGl`). 검사 내용은 그대로다.

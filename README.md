# 우리 아파트 피난로 그리기 · 우리집 대피지도

공동주택 세대의 평면을 직접 그리고, 소화기·세대 피난시설과 피난동선을 표기한 뒤,
화재 시 연기 확산을 시뮬레이션으로 체감하고 그 결과를 **A4 피난안내도 1매**로 인쇄해
집 안에 게시하도록 만든 교육용 웹 시스템이다.

- 설치·회원가입·서버가 필요 없다. 브라우저만 있으면 된다.
- 입력한 세대 정보와 도면은 **서버로 전송되지 않는다.** 모든 연산과 저장은 이용자 기기 안에서만 이뤄진다.
- 인터넷이 없는 교육장을 위해 **단일 HTML 배포본**(약 1MB)을 제공한다.
- **초등** / **중·고등·일반** 두 수준으로 나뉜다. 초등은 도화지에 그리듯 마우스로 끌어 집을 그리고,
  손을 떼면 반듯한 도면이 된다. 용어·기호 설명·필수 항목도 초등 눈높이로 바뀐다.
- 처음 열면 **따라하기**가 화면을 덮고 한 걸음씩 짚어 준다. **사용 설명서**는 언제든 열 수 있다.
- **그리기 도우미**가 "밖으로 나가는 문이 없다"처럼 다음에 할 일을 늘 한 줄로 알려 준다.
- 처음 열면 **누가 쓰는지**를 고른다. **초등학생 이하**는 블록을 놓아 집을 만들고 불이 난 집에서
  대피해 보는 **우리집 대피지도** 화면으로, **중고생·일반**은 치수를 다루는 작성 화면으로 들어간다.

> 본 시스템의 확산 해석은 소방 교육자료에서 통용되는 눈높이 수치를 채택한 **교육용 근사 모델**이며,
> 성능위주설계(FDS 등) 해석을 대체하지 않는다. 또한 **법정 피난안내도를 대체하지 않는다.**

## 왜 만들었나

공동주택 화재 사망자의 다수가 연기·유독가스 흡입(77.9%)과 야간 인지 지연(19–07시 61.6%)에서 발생한다.
세대별 평면과 피난시설이 제각각인 아파트에서는 "우리 집 기준"의 대피계획이 필요하지만,
이를 직접 그려 볼 수 있는 도구가 없었다.

## 9단계 절차

| 단계 | 하는 일 |
|---|---|
| 01 평면 작성 | 자유 그리기(손그림 자동 직선 보정) · 표준 평면 4종 호출(전용면적 자동 축척) · 도면 사진 자동 인식 · 직접 작도 |
| 02 세대 정보 | 동·호수, 사용승인 연도로 우리 집 피난시설 유형(1992/2005/2010 기준) 안내 |
| 03 개구부 | 현관문·실문·미닫이·창호 배치, 유효 폭과 상시 개방 여부 |
| 04 설비 표기 | 소화기, 대피공간·경량칸막이·하향식 피난구, 연기감지기 |
| 05 피난동선 | 주 동선 자동 생성, 대체 동선 추가, 구간별 보행거리·소요시간 |
| 06 확산 해석 | 발화 지점·원인 설정, 타임라인 스크러빙, 차단 면적 곡선, 동선별 ASET/RSET |
| 07 대피 훈련 | 행동 선택 → 노출 누적 → 등급(A~D)·판단 이력·검토 사항 |
| 08 자가 진단 | 도면 기준 자동 점검 12항목, 위험요소 자료 10종, 화재 시 행동 절차 |
| 09 산출물 | A4 가로 피난안내도 인쇄, PNG 저장, 프로젝트 파일(JSON) 저장·불러오기 |

1차시 45분 안에 완주할 수 있게 구성했다. (01–03 15분, 04–05 10분, 06–07 12분, 08–09 8분)

| 선택 막대 | 도면 위에서 무엇을 골랐는지 보여 주고 바로 지울 수 있다. |
| 처음부터 | 그린 것을 모두 지우고 다시 시작한다. 되돌리기로 복구된다. |

## 피난동선 그리기

구획실 하나에 동선 하나다. 시작과 끝이 분명하도록 이렇게 동작한다.

1. 동선 도구를 고르면 **아직 길이 없는 방**이 노란 점선으로 표시되고 "여기서 시작"이 뜬다.
2. 그 방 **안을** 눌러 시작한다. 방 밖에서는 시작되지 않는다(어느 방의 동선인지 분명해야 한다).
3. 그리는 동안 **종점(현관문·대피공간·경량칸막이·하향식 피난구)이 초록 과녁**으로 드러난다.
4. 과녁을 누르면 **거기서 저절로 끝난다.** 이름은 `침실3 → 현관문` 으로, 종점 종류까지 기록된다.
5. 끝나면 남은 방을 알려 준다. 이어서 다음 방을 눌러 그리면 된다.

도중에 그만두려면 화면 위 막대의 **취소**(또는 `Esc`), 종점에 닿지 않고 맺으려면 **여기서 끝내기**
(또는 더블클릭·`Enter`)를 누른다. 막대에는 지금 어느 방에서 출발했는지와 찍은 점 수가 늘 보인다.

## 화면 다루기

도면은 **늘 캔버스 한가운데** 머문다. 확대·축소를 해도, 창 크기가 바뀌어도 가운데를 지킨다.
일부러 옮겨 보고 싶으면 `Shift` 를 누른 채 끈다(스페이스·휠 버튼·손 도구도 같다).
초등 수준에서는 옮기지 않아도 늘 가운데 보이므로 몰라도 된다.

## 자유 그리기

상단 바에서 **초등**을 고르면 자유 그리기(단축키 `S`)가 기본 도구가 된다.
중·고등·일반 수준에서도 도구 막대에서 언제든 쓸 수 있다.

마우스로 끄는 동안에는 손그림 그대로 보이다가, 손을 떼는 순간 수평·수직 구간으로 펴지고
눈금(초등 10cm, 중·고등 5cm)에 맞춰진다. 무엇을 그렸는지는 몸짓으로 구분한다.

| 그린 모양 | 결과 |
|---|---|
| 닫힌 모양 (한 바퀴 둘러 그림) | **방** — ㄱ자·ㄷ자로 그려도 사각형 여러 개로 나눠 받는다. 이미 방이 있는 자리는 비켜 간다. |
| 방을 가로지르는 선 | **벽** — 그 자리에 벽이 서고 방이 둘로 나뉜다. 새 방 이름은 겹치지 않게 붙는다. |
| 벽을 따라 그은 짧은 선 | **문·창** — 그은 길이가 개구부 폭이 된다(60~280cm). |

옵션 막대에서 해석을 **자동 / 방 / 벽 / 문·창** 으로 고정할 수도 있다.
결과가 마음에 들지 않으면 `Ctrl`+`Z` 로 되돌린다.

보정 절차는 이렇다. Ramer–Douglas–Peucker 로 손떨림 잔점을 걷어내고, 구간마다 긴 축을
골라 수평·수직으로 붙인 뒤, 같은 축이 이어지면 하나로 합치고 짧은 계단은 흡수한다.
닫힌 모양은 끝을 시작점에 정확히 물린 다음, 격자선으로 잘라 낸 칸을 최대 사각형으로 묶어
방으로 만든다.

## 우리집 대피지도 (초등학생 이하)

첫 화면에서 **초등학생 이하**를 고르면 열리는 화면이다. 설계서는 `docs/DESIGN-v1.0.md` 와
변경 명세 `docs/DESIGN-v1.1-changes.md`, `docs/DESIGN-v1.2-changes.md` 다.
어긋나면 뒤 문서가 이긴다. 코드는 `src/kids/` 아래에 따로 있다.

```
그리기 ──▶ 대피경로 그리기 ──▶ 대피 게임 ──▶ 결과 리포트 ──┬──▶ 3D 로 다시 보기
   ▲              ▲                                       │
   │              └──────── [다시 해보기] ─────────────────┤
   └──────────────────────── [지도 고치기] ────────────────┘
```

| 축 | 하는 일 |
|---|---|
| 그리기 | 시작 평면 **8종**(방2·방3·방4·타워형·원룸·빌라·단독·복층)에서 출발해 방을 끌어 옮기고 크기를 바꾼다. 빈 도면에서 시작해도 된다. 팔레트 클릭 → 도면 클릭이면 표준 크기로 놓인다. 두 방이 맞닿으면 **문 후보**가 반투명으로 보이고 한 번 누르면 문이 된다. 겹치는 배치는 시도부터 막는다. 기본 팔레트는 7종 + 더보기 = 8칸. 마우스가 없어도 Tab·방향키·Enter 로 다 된다. |
| 필수와 그 밖 | 현관문·방문·내 자리·소화기·감지기가 **필수**다. 팔레트에 채움 표시가 붙고 점검 막대에 `있어야 하는 것 3/5` 가 뜬다. 빠진 채로 시작하려 하면 한 번만 물어보고, 막지는 않는다. |
| 문·창 | 개구부마다 **평소 열림/닫힘**이 있다. 도면에 그대로 보이고 골라서 한 번 눌러 바꾼다. 방화문 닫힘이 방문 닫힘보다 잘 막고, 닫힌 창은 연기를 막고, 열린 창은 오히려 돕는다. |
| 나가는 곳 | 1층 밖·**옥상**·**지하** 세 갈래다. 평소 길은 아래로 나가고(RULE-F-08), 불이 나면 지하로 내려가지 않는다(RULE-F-09). |
| 경로 | **주 경로**(현관)와 **보조 경로**(현관으로 못 나갈 때) 두 줄. 규칙 엔진이 각각 다른 `ScenarioKey` 로 평가한다. |
| 게임 | 2D 위험장 엔진. 발화점은 매번 랜덤이되 **시작 즉시 이길 수 없는 판은 내지 않는다.** 연기가 불보다 빠르고, 닫힌 문이 확산을 늦추며, 낮은 자세가 노출을 줄인다. 불과 연기는 단계로 나눠 그려 번져 나가는 앞머리가 보인다. 연습 모드(시간 무제한)가 기본, 도전 모드에서 게이지로 시간을 보인다. 엔진(`core/hazard/field.ts`)에는 재난 이름이 없고 프리셋 JSON 으로 받는다. |
| 시계 | **늘어나는 시각**이다. 줄어드는 제한이 아니라 나가기까지 몇 초 걸렸는지를 보이고, 성공하면 자기 최고 기록과 나란히 뜬다. 등수는 없다. |
| 소리 | 시작 신호음·감지기 경보(실물 T-3 패턴)·발소리·문 여닫는 소리·자세 소리·성공 팡파르를 Web Audio 로 합성한다. 캐릭터의 말은 브라우저 음성합성이 읽는다. 상단바에서 끌 수 있고, **실패에는 아무 소리도 내지 않는다.** 음원 파일은 싣지 않는다. 읽히는 문장은 `VOICE-SCRIPT.md` 에 모아 두었다. |
| 3D 리플레이 | 리포트에서 「3D 로 다시 보기」를 누르면 같은 판을 3차원으로 재생한다. 평면도를 그대로 세우고(문은 칸의 88%를 비운 진짜 문틀, 가구·가전은 종류마다 다른 모양), 기록된 칸을 따라가며, 그때의 불·연기를 함께 보인다. 기본은 **1인칭**이다 — 그때 그 눈높이로 지나온 길을 다시 본다(낮은 자세면 눈도 내려가고, 천장도 보인다). 뒤에서·위에서 시점도 있고, **끌어서 둘러보고 휠로 확대·축소**한다. 무사히 나왔으면 마지막에 **가족이 반기는 장면**으로 넘어간다(성공했을 때만). WebGL 을 못 쓰면 2D 로 조용히 내려간다. 라이브러리 없이 WebGL2 를 직접 쓴다. |
| 리포트 | 규칙 엔진(정적)과 플레이 로그(동적)를 합쳐 **잘한 점 / 고칠 점**으로 정리한다. 실패해도 잘한 점이 하나는 있고, 고칠 점은 세 개까지만 보인다. `[왜?]` 를 누르면 학습 카드가 그 자리에서 펼쳐진다. 점수·등급·순위는 없다. |
| 캐릭터 | 영이·웅이(설명)와 일구(발견·격려)가 **트리거 기반**으로 먼저 말을 건다. 자유 입력·검색은 없다. "이제 뭘 해야 해?"는 어느 단계에서든 답한다. 말풍선은 도면 아래 칸이라 지도를 가리지 않는다. 게임에서 내가 될 캐릭터는 **남학생 5명·여학생 5명** 열 명 중에 고른다. 얼굴 뼈대와 칠하는 방식은 같고 머리 모양·머리 색·피부 톤·옷 색·소품으로 갈린다. |
| 인쇄 | A4 세로 한 장 — 주·보조 경로, 못 나갈 때 미니맵, 우리 가족 약속, 손글씨 칸, 119, 가족과 함께 확인할 것. 흑백에서도 번호·선종류로 읽힌다. |

콘텐츠(학습 카드·캐릭터 대사·판정 문장·규칙 문장)는 `src/kids/content/` 의 JSON 이다.
모든 문장에 출처 id 가 있고, 출처가 **1차 대조 전**이면 화면에 "검수 대기"로 표시된다.
`npm run validate` 는 구조 오류만 막고, `npm run validate:strict` 는 미검수 출처도 막는다
(소방청 원문 대조가 끝나면 배포 워크플로를 strict 로 바꾼다).

## 시작하기

```bash
npm install
npm run dev          # http://localhost:3000
```

### 명령

| 명령 | 내용 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm run build` | 정적 내보내기 → `out/` |
| `npm run typecheck` | TypeScript strict 타입 검사 |
| `npm test` | 연산 로직 검증 151항목 (화면 없이 실행) |
| `npm run smoke` | Chromium 실조작 검증 73시나리오 (`npm run build` 후) |
| `npm run validate` | 어린이 화면 콘텐츠 검증 (개발 모드 · `--strict` 는 배포 모드) |

smoke 를 처음 실행하기 전에 `npx playwright install chromium` 이 한 번 필요하다.

## 배포

### 정적 웹

```bash
npm run build            # out/ 생성
```

`out/` 을 아무 정적 호스팅에나 올리면 된다. GitHub Pages 프로젝트 페이지처럼 하위 경로에
게시할 때는 기준 경로를 준다.

```bash
BASE_PATH=/저장소이름 npm run build
```

`main` 에 푸시하면 타입 검사와 로직 검증을 통과한 경우에만 GitHub Pages 로 배포하는
워크플로가 포함되어 있다(`.github/workflows/deploy.yml`). 저장소 설정에서
**Settings → Pages → Source: GitHub Actions** 를 한 번 지정하면 된다.

### 오프라인 배포본

```bash
npm run build:standalone
```

`dist/evacuation-planner.html` 하나만 USB 로 옮기면, 인터넷이 없는 교육장에서도
더블클릭으로 열린다. 외부 참조가 0건이 되도록 CSS·JS 를 전부 문서 안으로 넣고,
웹폰트는 시스템 글꼴로 대체한다.

HTML 에서 `<link>` 를 지우는 것만으로는 부족하다. Next.js 는 같은 참조를 스트리밍
페이로드에도 실어 보내고, 수화 과정에서 React 가 그것을 다시 넣기 때문이다. 그래서
빌드 자체를 오프라인 모드로 다시 돌려 웹폰트를 아예 렌더하지 않게 하고, 페이로드에 남은
스타일시트 경로는 내용이 담긴 data URL 로 바꾼다. `npm run smoke` 가 `file://` 에서
네트워크 요청 0건·오류 0건을 실제로 확인한다.

### 핵심 알고리즘

**벽체 생성** — 실 사각형의 경계선을 잘게 나누어 양쪽 점유를 조사하고, 양쪽 모두 실이면
내벽(110mm), 한쪽만 실이면 외벽(200mm)으로 두께를 준다. 개구부 폭만큼 벽을 절개해
문틀·문짝·회전반경을 그리며, 회전반경은 열리는 쪽 실의 여유 깊이를 넘지 않도록 제한한다.

**피난동선** — 종점(현관문·피난설비)에서 시작하는 거리장을 4방향 다익스트라로 계산하되,
벽면에 붙은 셀에 가산 비용을 두어 통로 중앙을 따르게 한다. 각 실 중심에서 내리막을 추적한 뒤
같은 방향 구간을 병합하고 ㄱ자 연결 검사로 꺾임을 최소화한다(직각 동선, 개구부 사선 관통 금지).

**연기 확산** — 매 프레임 물리 연산 대신 발화점에서 각 셀까지의 **도달 시각**을 8방향
다익스트라로 한 번만 계산한다(열린 공간 0.9m/s, 닫힌 문 약 80초 지연, 화재 원인별 성장 배수).
덕분에 타임라인을 임의 시각으로 즉시 옮길 수 있고, 84㎡ 평면 전 시간대 해석이 1초 안에 끝난다.

연기 선단이 지나갔다고 곧바로 지나갈 수 없게 되는 것은 아니다. 연기층이 내려와 시야와 호흡을
막기까지 걸리는 시간을 농도 상승(60초)으로 근사하고, 농도 0.5를 넘긴 시각을 그 지점의
**차단 시각**으로 본다. 동선별 ASET 은 동선 위에서 가장 먼저 차단되는 시각이고,
RSET 은 인지 10초에 보행 시간을 더한 값이다.

**대피 훈련** — 행동 선택마다 시간이 흐르고, 이동 경로를 샘플링해 그 시각의 연기 농도 ×
노출 시간을 신체 상태에 누적한다. 자세 낮추기(노출 ×0.45, 보행 ×0.7)·호흡 보호(×0.6)·
문 폐쇄(유입 지연 2배)의 보호 효과를 반영하고, 종료 시 등급(A~D)과 검토 사항을 제시한다.

## 접근성

전 도구에 키보드 단축키를 배정했고(`?` 로 목록 확인), 포커스 표시 2px 아웃라인,
`aria-pressed`/`aria-label` 부여, 색상 외 형태(아이콘·선 두께·점선)로도 상태를 구분한다.
본문 대비비는 두 화면 모두 4.5:1 이상을 지킨다(큰 글자 3:1). 어린이 화면은
`npm run smoke` 가 편집·게임·리포트의 **모든 글자와 모든 단추를 전수로** 재어 확인한다.

| 항목 | 어린이 화면 | 일반 화면 |
|---|---|---|
| 누르는 것의 최소 크기 | **48×48** (설계서 v1.1 §2.2 D6) — `--k-hit` 한 곳에서 정한다 | 조밀한 작업 화면이라 상향하지 않았다 |
| 본문 대비 | 4.5:1 (자동 검증) | 4.5:1 |
| 키보드만으로 | 된다 — Tab 으로 도면에 들어가 방향키로 칸을 옮기고 Enter 로 누른다 | 전 도구 단축키 |
| 움직임 줄이기 | `prefers-reduced-motion` 존중 | 〃 |

어린이 화면에서 도면을 다루는 데 마우스가 필요 없다. Tab 으로 도면에 초점을 주면
노란 칸이 나타나고, 방향키로 옮긴 뒤 Enter 를 누르면 그 자리를 누른 것과 같다.
방 놓기·문 후보·내 방 고르기·길 잇기·지우기가 모두 같은 길로 처리된다.

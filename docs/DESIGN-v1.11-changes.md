# 우리집 대피지도 변경 명세 v1.11 — 편집 버그 수정과 게임형 3D 보강

이 문서는 v1.10 이후의 변경 정본이다. 충돌할 때 v1.11이 앞선다.

## 1. 범위와 불변 조건

- `inst.md`의 다섯 지시를 한 번에 구현하고 로직·Chromium·인쇄로 각각 재현 검증한다.
- 편집기·2D 대피연습·인쇄는 `PlanSvg` 하나를 계속 사용하며 3D는 결과 리플레이에만 둔다.
- 실제 발화 문장은 바꾸지 않는다. `VOICE-SCRIPT.md`와 ElevenLabs MP3는 이번 작업 대상이 아니다.
- 외부 모델·이미지·HDRI·글꼴을 런타임에 받지 않고 단일 오프라인 HTML 4MB 제한을 지킨다.

## 2. 가구의 실제 크기

- 점 블록은 선택적으로 `size: { w, h }`를 가진다. 이전 저장자료에서 이 값이 없으면 콘텐츠의
  `blocks.json` 표준 크기를 읽어 채운다.
- 침대는 2×3칸, 싱크대와 소파는 3×1칸, 책상·옷장·책장·TV는 2×1칸, 식탁은 2×2칸으로 보인다.
  한 칸 가전·안전설비·사람 표시는 그대로 둔다.
- 배치·선택 윤곽·누름 판정·끌기 미리보기·여럿 고르기·도면 경계 검사는 같은 크기를 사용한다.
- 3D 가구도 같은 크기를 사용해 2D에서는 긴 침대가 3D에서 다시 한 칸으로 줄지 않게 한다.

## 3. 문과 창 편집

### 3.1 길이

- 여닫이문·현관문·여닫이창은 1~3칸, 미닫이문·미닫이창은 1~6칸으로 조정한다.
- 현재 기준점의 한쪽에 자리가 없어도 같은 벽의 반대쪽에 자리가 있으면 기준점을 자동 이동해
  요청한 길이를 만든다. 어느 쪽에도 연속된 벽이 없거나 다른 개구부와 겹치면 바꾸지 않는다.

### 3.2 열림 방향

- 여닫이문 계열은 `swing: inward | outward`를 가진다. 이전 자료의 기본은 `inward`다.
- 선택 조작부의 `방 안으로`, `방 밖으로` 단추로 한 번에 전환하고, 2D 편집·인쇄에서 문짝과
  회전 호가 벽의 어느 쪽으로 열리는지 바로 보이게 한다.
- 미닫이문·창·트인 통로에는 안팎 방향 단추를 보이지 않는다.

### 3.3 이동

- 문·창을 고른 뒤 벽을 따라 끌어 새 벽자리로 옮길 수 있다. 길이가 2칸 이상이면 전체 길이가
  연속된 벽 위에 있고 다른 개구부와 겹치지 않을 때만 놓인다.
- 가구·안전설비·사람 표시도 보이는 전체 크기를 잡아 끌 수 있다. 도면 밖으로 나가는 이동은 막는다.
- 문·창을 단순히 고르는 동작이 평소 열림/닫힘 상태를 몰래 바꾸지 않는다.

## 4. 내 위치 한 명 원칙

- 도면에는 `my_spot`이 최대 한 개만 존재한다. 저장자료를 불러올 때 여러 개면 마지막 한 개만 남긴다.
- 2D 대피연습에서는 고정 `my_spot` 그림을 숨기고 움직이는 게임 플레이어만 그린다.
- 3D 리플레이는 기록된 플레이어 한 명만 그린다. 형·누나·동생 표시는 주인공으로 복제하지 않는다.

## 5. 대피경로가 없는 출력 차단

- 주 경로와 보조 경로가 모두 없으면 하단 `뽑기`, 결과의 `인쇄`, `Ctrl+P`, PNG 저장과 실제 인쇄를
  진행하지 않는다.
- 대신 `먼저 나가는 길을 그려야 지도를 뽑을 수 있어.`라고 화면 알림을 띄우고 주 경로 그리기
  단계와 도구로 이동한다.
- 하나 이상의 대피경로가 있으면 미리보기·PNG·실제 인쇄를 정상 허용하고 출력물에 경로를 표시한다.

## 6. Hology 참고 3D 보강

Hology 공식 사이트가 강조하는 지형 편집, 다양한 재질, 자연스러운 캐릭터 이동, 커스텀 셰이더,
절차형 초목의 시각 원리를 참고한다. 엔진이나 자산을 복제하지 않고 현재 Three.js 절차형 장면에
다음 원리만 적용한다.

- `고급` 화질은 DPR 상한을 2.5로 올리고 1024px 절차 표면, 4096 그림자, AO와 블룸을 사용한다.
- 잔디 바닥에는 색·미세 높낮이를 섞는 절차 셰이더와 잔디 군집을 더해 평면 한 장처럼 보이지 않게 한다.
- 바닥 재질은 색상뿐 아니라 거칠기 차이를 강화하고, 창·금속·목재가 조명에 서로 다르게 반응한다.
- 이동 캐릭터는 걷기 위상과 몸의 상하 움직임을 이어 기존 정지 관절 인상을 줄인다.
- 장면 아래 HUD에 현재 `고급/높음/가벼움` 화질을 표시해 실제 선택 화질을 알 수 있게 한다.
- 자동 검증 환경은 계속 `가벼움`으로 시작해 소프트웨어 WebGL 과부하를 막는다.

참고: [Hology Engine 공식 사이트](https://hology.app/ko-kr) — 지형 편집·재질, 캐릭터 이동,
커스텀 셰이더, 절차형 초목 소개.

## 7. 검증과 완료 기준

- `npm test`: 가구 표준 크기, 문 길이 자동 맞춤, 열림 방향 기본값·전환, 중복 내 위치 정규화,
  출력 가능 조건을 순수 로직으로 검증한다.
- `npm run smoke`: 침대·싱크대 크기, 가구·문·창 끌기, 문 3칸 확장과 안팎 방향, 게임 플레이어
  한 명, 경로 없는 뽑기 차단과 경로 뒤 허용을 실제 Chromium에서 조작한다.
- `npm run shots`: 1024×768과 1440×900의 편집 화면과 `고급` 3D 세 시점을 찍어 가구 비율,
  문 방향, UI 잘림, 지형·재질·캐릭터 한 명을 눈으로 확인한다.

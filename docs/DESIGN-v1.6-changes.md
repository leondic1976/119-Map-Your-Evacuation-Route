## 1. 팔레트 — 칸을 좁혀 더 많이 보인다

패널만 넓히면 칸도 같이 커져 보이는 수가 늘지 않는다. **칸 자체를 좁힌다.**

| | 전 | 후 |
|---|---|---|
| 칸 최소 폭 | 절반(2줄 고정) | **84px** — 폭에 맞춰 채운다 |
| 칸 높이 | 92px | 78px |
| 그림 자리 | 36px | 32px |
| 이름 글자 | 12px | 11px |

- 줄 수를 못 박지 않고 `repeat(auto-fill, minmax(84px, 1fr))` 로 둔다.
  패널을 넓히면 저절로 한 줄이 더 생긴다. 기본 여덟 칸도 같은 규칙을 쓴다.
- 84×78 이므로 누르는 칸은 **48px 을 넉넉히 넘는다** (D6 · NFR-10).

## 2. 화재 한 종에 집중한다

기본판은 원래 화재 1종이었지만(작업지침 §9-11) 지진·침수·가스의 **학습 카드와
온보딩 물음이 남아** 있었다. 아이가 아직 배우지 않을 것을 읽고, 쓰지도 않을 답을 했다.

- **학습 카드** — `quake.*`·`flood.*`·`gas.*` 를 `content/guide/cards-extension.json` 으로
  옮긴다. 지우지 않는다. 확장판을 열 때 도로 들이면 된다.
  다만 **기본판 콘텐츠가 아직 가리키는 카드는 남긴다** — `gas.valve` 는 가스 중간밸브
  블록의 「왜?」라서 화재에서도 쓴다. 카드 37장 · 확장판 13장.
  하한을 40장에서 **30장**으로 내린다.
- **온보딩의 「1층이나 반지하야?」를 없앤다.** 이 답은 침수 규칙(RULE-W-01·02)과
  침수 목표 선택에만 쓰였다. 화재에서는 한 번도 읽지 않는다.
  온보딩이 **5회 → 4회 조작**으로 짧아진다 (v1.1 §2.5 개정).
- `profile.lowFloor` **필드는 남긴다.** 저장 스키마를 또 바꾸지 않기 위해서다(v1.1 의 판단
  그대로). 기본값 `false` 로 두고 확장판이 열릴 때 물으면 된다.
- 침수·지진·가스 **규칙은 `EXTENSION_RULES` 에 그대로** 있다. 손대지 않는다.

## 3. 결함 — 소리 켬/끔이 듣지 않는다

**증상**: 껐는데 계속 나거나, 켰는데 나지 않는다.

**원인 다섯**:
1. 부르는 쪽이 저마다 `profile.soundOn` 을 들고 다녔다. 말풍선은 `soundOn || ttsEnabled`
   로 봐서 **소리를 꺼도 계속 읽었다.**
2. `AudioContext.suspend()` 는 **이미 예약된 소리를 취소하지 않는다.** 다시 켜면 멈췄던
   감지기 경보가 이어서 울릴 수 있었다.
3. 첫 `AudioContext` 생성이 실패해도 잠금 해제가 끝난 것으로 기록해, 다음 조작에서 다시
   시도하지 않았다.
4. 게임의 지연 음성 타이머가 정리되지 않아 게임 화면을 떠난 뒤에도 말을 시작할 수 있었다.
5. 성공과 동시에 게임 화면이 결과 화면으로 교체되어, 게임 화면의 성공음 effect가 실행되기 전에
   사라졌다.

**고침**: 켬/끔의 기준을 `ui/sound.ts` 한 곳으로 모은다.

- `setSoundEnabled(on)` 하나가 잠근다. 호출부는 `soundOn` 복사본을 인자로 넘기지 않는다.
- 끄면 현재·예약 `OscillatorNode` 를 모두 **stop·disconnect** 하고 나서 `AudioContext` 를
  suspend 한다. 읽던 말·음원·지연 타이머도 함께 끊는다.
- 켜면 resume 한다.
- 잠금 해제는 이용자의 다음 조작마다 재시도할 수 있다. 실패를 영구 상태로 저장하지 않는다.
- **처음에는 꺼 둔 채로 뜬다.** 저장을 읽기 전에는 아무 소리도 내지 않는다.
  켜는 것은 `boot()` 가 저장을 읽은 직후 한 번, 아이가 단추를 누를 때 한 번뿐이다.
  이걸 안 하면 **껐던 아이가 앱을 다시 열자마자 소리를 듣는다** — 첫 대사가
  설정을 읽기 전에 이미 소리를 내 버린다.
- **켬/끔만은 즉시 저장한다.** 다른 것은 600ms 뒤에 모아 저장하는데, 소리를 끄자마자
  창을 닫으면 그 저장이 날아가 다음에 열 때 또 소리가 난다.
- 창을 떠날 때(`pagehide`·`beforeunload`)와 탭을 숨길 때 소리와 말을 끊는다.
- 성공 화음은 결과 화면으로 바꾸기 전에 시작하고, 뒤따르는 성공 음성 타이머는 끄기·화면 이탈 때
  함께 취소한다.

## 4. 사람 목소리를 넣을 자리 (VOICE-SCRIPT.md §4 구현)

음원 자체는 아직 없다. **넣을 자리와 굽는 길을 먼저 만들어 둔다.**

- `src/content/voice.ts` — 여덟 대사의 id·글·data URI 자리.
- `npm run voice` (`tools/voice-bake.ts`) — `content/voice/*.mp3` 를 data URI 로 구워 넣는다.
  파일 참조로 두지 않는 것은 오프라인 배포본이 외부 참조 0건이어야 하기 때문이다(NFR-1).
  합쳐 1MB 를 넘으면 실패시킨다 — 단일 HTML 4MB 상한을 지키기 위해서다(NFR-3).
- `playVoice(id)` — 음원이 있으면 틀고, 없으면 **음성합성으로 넘어가고**,
  그것도 없으면 조용히 넘어간다. 화면의 글은 늘 그대로 있다.
- 지금 이어 둔 자리는 넷이다 — 시작(`v-start`), 몸 낮추기(`v-crouch`),
  문 닫기(`v-close`), 성공(`v-success`). 나머지 넷은 음원이 들어온 뒤 이어도 늦지 않다.

# 우리집 대피지도 변경 명세 v1.17

작성일: 2026-09-03

대상: 방 크기 조절 화면

우선순위: 이 문서가 v1.16보다 뒤의 결정이며 충돌하면 v1.17이 이긴다.

## 1. 문제

방을 선택하면 도면에 직접 조작할 수 있는 크기 손잡이가 나타나는데도 상단에 가로·세로 증감 단추가 함께 나타나 조작부가 중복된다. 상단 공간을 차지하고 아이가 어느 방법을 써야 하는지 망설이게 한다.

## 2. 방 크기 조절

- 벽이 있는 방을 선택해도 상단에 방 크기 증감 단추를 표시하지 않는다.
- 선택한 방의 도면 테두리에 나타나는 8방향 손잡이는 그대로 유지한다.
- 아이는 원하는 손잡이를 마우스로 끌어 방을 늘리거나 줄인다.
- 방 안쪽을 끌어 옮기는 조작과 문·창·가구의 기존 크기 조절은 그대로 유지한다.
- 트인 주방(부엌)은 기존처럼 빠른 추가의 `트인 주방(부엌) 다시`를 눌러 범위를 다시 그린다.

## 3. 캔버스 중심 화면

- 처음 편집 화면에서는 오른쪽 사용법을 접어 두고, 필요할 때 48px 이상의 `펴기` 단추로 연다.
- 접힌 사용법 영역은 단추를 누르는 데 필요한 폭만 차지한다.
- 상단·하단 고정 막대는 48px 누름 크기를 해치지 않는 최소 높이로 줄인다.
- 캔버스 아래의 캐릭터 해설 칸과 점검 줄은 내용을 읽고 조작할 수 있는 최소 높이로 줄인다.
- 캔버스 안쪽의 장식용 여백을 줄여 실제 도면이 차지하는 폭과 높이를 늘린다.
- 캐릭터 해설 칸은 축소한 뒤에도 고정 높이를 유지해 말풍선이 나타날 때 도면 크기가 달라지거나 겹치지 않게 한다.

## 4. 검증

- 소스 검사에서 상단 방 크기 조절부가 없고 도면의 8방향 손잡이가 남아 있는지 확인한다.
- Chromium에서 방을 선택했을 때 상단 증감 단추가 나타나지 않고 손잡이 여덟 개가 나타나는지 확인한다.
- Chromium에서 손잡이를 실제로 끌어 방 크기가 저장되고 외곽 바닥이 정상 재구성되는지 확인한다.
- 1024×768, 1440×900, 1920×1080에서 캔버스와 고정 막대의 크기를 재고 화면 밖 넘침이 없는지 확인한다.

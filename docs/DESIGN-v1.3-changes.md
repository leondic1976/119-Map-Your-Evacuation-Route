## 1. 화면은 하나뿐이다

### 1.1 이용자 고르기 화면 폐지

v1.0 §1 은 초등학생 이하와 중고생·일반을 나눠 첫 화면에서 고르게 했다.
**중고생·일반용 작성 화면을 폐지한다.** 이 저장소는 초등학생용 「우리집 대피지도」 하나만 만든다.

- 고를 것이 없으므로 **첫 화면(이용자 고르기)도 없앤다.** 열면 바로 온보딩(§2.5)이 뜬다.
- 상단바의 「첫 화면」 단추를 없앤다. 최상위 화면이므로 되돌아갈 곳이 없다.
- 작업지침 §5 「나가는 길」은 덮개·모달에만 적용된다 — 닫기와 `Esc` 는 그대로 둔다.

`profile.gradeMode`(`'easy'` · `'normal'`)는 **그대로 남는다.** 이것은 이용자를 나누는 값이
아니라 **읽는 눈높이**를 나누는 값이다. 기능은 같고 말만 달라진다. 기본값은 `'easy'` 다.

### 1.2 층 나누기 — 껍데기를 갈아 끼울 수 있어야 한다

나중에 Electron 으로 감싸 오프라인 설치본을 만들 수 있도록 의존 방향을 한 줄로 못 박는다.

```
core  →  (아무것도 부르지 않는다)
store →  core · content · platform
ui    →  store · core · content · platform
app   →  ui
```

- `core/**` 는 `react`·`zustand`·`document`·`window` 를 부르지 않는다 (v1.0 §3.3 을 기계 검사로 승격).
- **`platform/**` 이 바깥 세계에 닿는 유일한 자리다.** `localStorage`·파일 내보내기·
  `URL.createObjectURL` 을 다른 데서 부르지 않는다. 데스크톱 껍데기는 `Host` 를 구현해
  `setHost()` 로 갈아 끼우고, 나머지 코드는 손대지 않는다.

두 가지 모두 `tools/qa-tests.ts` 가 검사한다. 어기면 `npm test` 가 실패한다.

## 2. 집 모양 고르기 (§2.5 1단계 개정)

### 2.1 결함 — 카드 이름이 어른 말이다

**증상**: 블록은 `blocks.json` 의 `easy` 필드로 쉬운 이름을 갖는다(경량칸막이 → 부수는 벽).
그런데 `TemplateDef` 에는 `easy` 가 없어, **집 모양 카드만 쉬운 말 체계를 빠져나간다.**
`gradeMode` 가 `'easy'` 여도 "타워형 아파트"·"복층"·"빌라·다세대"가 그대로 나온다.

아이가 처음 만나는 화면인데 여기가 제일 어렵다. "타워형"은 부동산 용어이고,
"다세대"는 법률 용어이며, "빌라·다세대"는 작업지침 §5(가운뎃점 든 짧은 말은 풀어 쓴다)도 어긴다.

**고침**: `TemplateDef` 에 **`easy` 를 필수 필드로 더한다.** 블록과 같은 방식이다.

| id | `label` (보통) | `easy` (쉬움) |
|---|---|---|
| `apt_2room` | 방 두 개 아파트 | 방 두 개 아파트 |
| `apt_3room` | 방 세 개 아파트 | 방 세 개 아파트 |
| `apt_4room` | 방 네 개 아파트 | 방 네 개 아파트 |
| `apt_tower` | 타워형 아파트 | 방이 빙 둘러싼 아파트 |
| `duplex` | 복층 | 위아래 두 층인 집 |
| `house_1f` | 단독주택 1층 | 마당 있는 집 |
| `studio` | 원룸 | 방 하나인 집 |
| `villa` | 빌라·다세대 | 빌라 |

`npm run validate` 가 `easy` 가 빠진 템플릿을 막는다.

### 2.2 결함 — 모르는 아이가 막힌다

**증상**: 초1~2 는 자기 집이 타워형인지 판상형인지 모른다. 어른도 헷갈린다.
온보딩 2단계(1층·반지하)에는 "잘 모르면 어른께 여쭤봐도 돼"가 있는데 1단계에는 없다.

그런데 안내만 두면 **아이가 거기서 멈춘다.** 지금 옆에 어른이 없을 수 있고, 남은 길이
「직접 그릴래요」(빈 도면)뿐인데 그것은 아홉 칸 중 **제일 어려운** 선택지다.
모르는 아이를 백지로 보내는 것은 거꾸로다.

**고침**: **「잘 모르겠어」 카드**를 격자 맨 뒤에 둔다.

- 누르면 **`apt_2room`(가장 흔한 모양)을 실어 바로 다음 단계로 간다.** 되묻지 않는다.
- 카드에 한 줄을 적는다 — "나중에 바꿀 수 있어. 집에 가서 어른께 여쭤봐도 돼."
- 조작이 늘지 않는다. 다른 카드와 똑같이 **한 번 누르면 끝난다** (v1.1 §2 그리기 편의 우선).
- 맨 앞이 아니라 **맨 뒤**에 둔다. 앞에 두면 맞는 것을 찾아보지도 않고 누른다.
  카드를 훑어보고 못 찾았을 때 눈에 들어와야 한다.

고르는 화면은 **8종 + 빈 도면 + 잘 모르겠어 = 10칸**이다 (v1.2 §1.2 의 9칸을 갱신한다).

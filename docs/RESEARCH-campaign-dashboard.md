# 어린이 우리집 대피지도 캠페인 대시보드 연구보고서

작성일: 2026-08-31
대상: 소방서·교육지원청·학교/어린이집·학급·보호자가 함께 보는 PC용 캠페인 사이트

## 1. 연구 질문과 결론

질문은 “많은 학생의 대피지도를 지역과 학교 단위로 어떻게 관리하면서도 어린이가 감시받거나
순위 경쟁을 한다고 느끼지 않게 할 것인가?”이다. 결론은 다음과 같다.

1. 관리 계층은 `시도 → 시군구 → 읍면동 → 학교 → 학년 → 반 → 학생 활동`으로 고정한다.
2. 첫 화면은 숫자를 늘어놓는 행정 화면이 아니라 “우리 동네가 함께 만드는 안전 약속”을 보여 주는
   캠페인 홈으로 만든다. 밝은 삽화, 오늘 할 일, 참여 현황, 안전 행동을 같은 화면에 둔다.
3. 학생을 점수 순으로 세우지 않는다. `지도 완성`, `소화기 확인`, `두 대피경로`, `대피연습`의
   준비 상태와 도움이 필요한 항목만 보여 준다. 개인 이름은 권한이 있는 학급 화면에서만 다룬다.
4. 현재 GitHub Pages 배포는 중앙 서버가 없으므로 **체험 데이터와 현재 브라우저의 기록만** 사용한다.
   실제 기관 공동 관리는 인증·동의·역할 권한·보관/삭제 정책·감사 기록이 준비된 다음 단계다.
5. 지역·학교 기준정보는 코드와 표시 이름을 분리한다. 행정구역 개편 때 UI를 다시 짜지 않고 코드
   테이블만 갱신하도록 한다.

## 2. 공식 자료에서 얻은 설계 근거

### 어린이에게는 참여 경로와 활동이 먼저다

미국 Ready.gov Kids는 어린이·가족·교육자를 별도 진입점으로 나누고 게임, 가족 계획, 교실 자료를
연결한다. 자료실도 대상·학년·주제·언어 필터를 둔다. 따라서 대시보드도 하나의 복잡한 표보다
`소방서`, `학교`, `선생님`, `보호자`의 할 일을 먼저 보여 주고, 필요할 때 관리표로 내려가야 한다.

- [Ready.gov Kids](https://www.ready.gov/kids)
- [Ready Kids 자료실](https://www.ready.gov/kids/kids-resource-library?page=1)

소방청은 어린이가 화재 대피를 쉽고 재미있게 익히도록 공식 캐릭터와 애니메이션을 활용하며, 공동주택
대피계획 캠페인에서는 가족이 함께 상황별 계획을 세우는 것을 강조한다. 그러므로 삽화는 공포·불꽃보다
“함께 확인하고 안전하게 연습하는 모습”을 중심에 두고, 콘텐츠는 가족 확인 활동으로 이어져야 한다.

- [소방청 어린이 화재 대피 애니메이션](https://www.nfa.go.kr/nfa/news/pressrelease/press/?cntId=2641&mode=view&pageIdx=1)
- [소방청 아파트 화재 피난안전대책 개선 캠페인](https://www.nfa.go.kr/nfa/news/pressrelease/press/?cntId=2067&mode=view&pageIdx=2&searchCondition=all)

학교안전지원시스템은 현재 현황을 한눈에 보여 주는 요약과 인기 교육 콘텐츠를 함께 제공하고,
학교 안전교육을 학년·발달 단계와 안전 영역에 맞게 분류한다. 대시보드에 집계 숫자뿐 아니라
학급에서 바로 쓸 활동 카드와 다음 행동을 함께 두는 근거다.

- [학교안전지원시스템](https://www.schoolsafe24.or.kr/index.jsp)
- [학교 안전교육 실적 관리 절차](https://www.schoolsafe24.or.kr/front/contents/12015/cntntsView.do?menuSn=487&upperMenuSn=145)
- [학교 안전교육 자료 분류](https://www.schoolsafe24.or.kr/front/contents/10036/cntntsView.do?menuSn=488&upperMenuSn=148)

### 지역과 학교 기준정보는 바뀔 수 있다

행정표준코드관리시스템은 법정동 자료에 시도·시군구·읍면동 코드와 상위 코드를 제공한다. 학교알리미
Open API는 시도·시군구와 학교급으로 학교 기본정보를 조회할 수 있다. 2026년 7월에도 행정체제 개편에
따라 학교알리미 시군구 코드가 바뀌었으므로, 지역 이름을 학생 기록에 직접 중복 저장하기보다 버전이
있는 기준정보로 관리해야 한다.

- [행정표준코드 법정동 목록](https://www.code.go.kr/stdcode/regCodeL.do?menuNo=101010100010)
- [학교알리미 학교기본정보 Open API](https://www.schoolinfo.go.kr/ng/go/pnnggo_a01_l0.do)
- [2026년 학교알리미 시군구코드 변경 안내](https://www.schoolinfo.go.kr/ng/no/pnngno_a01_s0.do?notice_no=00000000000000000000000000000259)

### 아동 개인정보는 별도 경계가 필요하다

개인정보보호위원회 안내서는 아동·청소년을 개인정보 자기결정권을 행사할 정보주체로 본다. 이 서비스는
이름, 학교, 학급, 가정 내부구조를 결합할 수 있어 실제 공동 운영 단계에서는 특히 조심해야 한다.
공개 화면에는 개인 이름·집 도면을 노출하지 않고, 학생 상세는 최소 권한과 목적에 맞춘 기간 동안만
제공하는 구조가 필요하다.

- [아동·청소년 개인정보 보호 안내서(2024.12)](https://www.privacy.go.kr/front/bbs/bbsView.do?bbsNo=BBSMSTR_000000000049&bbscttNo=20783)

## 3. 이용자와 핵심 과업

| 이용자 | 가장 먼저 알고 싶은 것 | 허용할 화면 |
|---|---|---|
| 소방서 캠페인 담당 | 지역·학교 참여율, 도움이 필요한 안전 항목 | 지역/기관 집계, 캠페인 자료 |
| 교육지원청·학교 관리자 | 학년·반 진행 상태, 교사 지원 필요 | 소속 학교·학급 집계 |
| 담임·안전 담당 교사 | 누가 시작/완료했는지, 무엇을 확인할지 | 담당 반 학생 상태, 활동 안내 |
| 보호자 | 우리 아이 지도와 가족이 확인할 항목 | 연결된 자녀의 자료만 |
| 학생 | 우리 반이 함께 안전해지는 과정, 다음 활동 | 개인 활동과 반의 익명 집계 |

## 4. 정보구조

```text
/dashboard/
├─ 캠페인 홈
│  ├─ 지역·학교·학급 필터
│  ├─ 오늘의 안전 현황
│  ├─ 4대 안전 준비 진행률
│  └─ 역할별 바로 할 일
├─ 참여기관
│  ├─ 시도 → 시군구 → 읍면동
│  └─ 학교 → 학년 → 반
├─ 학생 활동
│  ├─ 검색과 상태 필터
│  ├─ 시작/작성 중/확인 필요/완료
│  └─ 최근 활동
├─ 캠페인 자료
│  ├─ 교실 활동 순서
│  ├─ 가정 확인 체크리스트
│  └─ 소방서 방문교육 안내
└─ 운영 안내
   ├─ 안전 완성도 기준
   ├─ 개인정보·권한
   └─ 데이터 연결 상태
```

첫 구현은 이 구조를 한 페이지의 앵커 탭과 필터로 제공한다. 사용자가 독립 사이트의 전체 구조를
미리 체험할 수 있고, 후속 라우트를 만들 때 데이터와 컴포넌트를 그대로 나눌 수 있다.

## 5. 표시 지표

### 상단 핵심 지표

- 참여 어린이 수: 선택 범위의 기록 수
- 지도 완성: 구조와 기본 위치를 모두 작성한 기록
- 소화기 확인: 실제 위치를 보호자와 확인한 기록
- 두 길 준비: 주·보조 대피경로가 모두 있는 기록
- 대피연습: 한 번 이상 실제 게임 연습을 마친 기록

### 안전 완성도

기존 총점 100은 행정 요약에만 유지한다. 학생 목록에서는 총점보다 네 영역의 상태를 우선한다.

| 영역 | 배점 | 의미 |
|---|---:|---|
| 집 구조 | 20 | 방과 현관문·방문을 표현했는가 |
| 안전 위치 | 25 | 내 위치·모이는 곳·소화기 등 실제 위치를 확인했는가 |
| 대피경로 | 30 | 주 경로와 보조 경로를 모두 그렸는가 |
| 대피연습 | 25 | 게임 연습과 안전 행동을 수행했는가 |

점수로 학생을 정렬하거나 상위권 배지를 주지 않는다. `도움 필요 → 작성 중 → 함께 확인 → 준비됨`의
상태만 사용하고, 지역·학교 차트도 순위가 아닌 목표 대비 진행률로 그린다.

## 6. 학생 친화적 시각 방향

- 배경: 학교와 안전한 동네, 웃는 어린이와 친근한 소방 안전 캐릭터. 불길·연기·공포 표정은 제외한다.
- 색: 짙은 남색을 정보 골격으로, 청록을 완료, 산호색을 행동, 노랑을 따뜻한 강조로 사용한다.
- 형태: 18~28px 둥근 카드, 큰 아이콘, 짧은 문장, 넉넉한 여백. 표도 줄 전체가 아닌 상태 칩으로 읽는다.
- 접근성: 텍스트 대비 4.5:1 이상, 색 외에 글자/아이콘으로 상태 병기, 포커스 표시, 48px 조작 영역.
- PC 전용: 1280~1920px을 기본으로 하고 1024px 아래에서는 대시보드 기능 대신 PC 안내를 제공한다.

## 7. 데이터와 개인정보 경계

### 현재 정적 체험판

- 코드에 포함된 가상 지역·학교·학생 기록과 현재 브라우저의 작성 기록만 합친다.
- 네트워크로 학생 자료를 업로드하지 않는다.
- 가상 자료에는 `데모` 표시, 로컬 자료에는 `이 PC` 표시를 붙인다.
- 내보내기·공유·기관 로그인처럼 서버가 필요한 단추는 실제 기능인 것처럼 꾸미지 않는다.

### 기관 공동 운영판에 필요한 것

- OIDC/SAML 기관 로그인, 역할 기반 접근제어(RBAC), 소속 범위 강제
- 보호자/법정대리인 동의와 아동에게 맞는 쉬운 고지
- 이름과 집 도면의 분리 저장, 전송/저장 암호화, 최소 수집
- 보관 기간과 학년 종료 후 삭제/익명화, 열람·수정·삭제 절차
- 관리자 조회·다운로드 감사 기록, 대량 다운로드 제한
- 집 도면 원본은 기본 비공개이며 집계에는 파생 상태만 사용

## 8. 성공 기준

- 처음 방문한 교사가 30초 안에 지역/학교/학급을 고르고 작성 중 학생을 찾는다.
- 지역을 바꾸면 하위 지역·학교·학년·반 선택이 일관되게 초기화된다.
- 모든 필터 조합의 요약 카드·차트·학생 표가 같은 자료 집합을 사용한다.
- 빈 결과, 데모/로컬 구분, 개인정보 고지가 화면에서 숨지 않는다.
- 키보드만으로 필터·탭·학생 행·대피지도 돌아가기를 사용할 수 있다.
- 1024, 1280, 1440, 1920px에서 가로 스크롤 없이 핵심 카드와 필터를 읽는다.

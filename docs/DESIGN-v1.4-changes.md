## 0. 변경 배경

지금 리플레이는 **구도는 맞지만 그림이 밋밋하다.** 회색 벽, 그림자 없음, 길 표시 없음.
목표 그림은 잘린 인형집을 비스듬히 내려다보며, 바닥에 빛나는 초록 길이 흐르고,
출구에 표지가 서 있고, 불난 자리가 붉게 테두리 지고, 오른쪽에 유리판 같은 조작 패널이 떠 있다.

### 0.1 목표 그림에서 **가져올 것**

| # | 요소 | 지금 |
|---|---|---|
| 1 | 잘린 인형집을 비스듬히 내려다보는 기본 구도 | 「위에서」 시점에 이미 있다 — 기본값으로 올린다 |
| 2 | 바닥에 흐르는 **빛나는 초록 길과 화살표** | 없다 |
| 3 | 출구 위 **표지판**과 집 밖 **안전지대 원** | 없다 |
| 4 | 불난 자리의 **붉은 테두리 구역 표시** | 불꽃만 있다 |
| 5 | 방마다 다른 바닥 색 · 따뜻한 실내광 · 그림자 · 접촉 그늘 | 색은 있으나 조명이 평평하다 |
| 6 | 집 밖 **잔디·나무·길** | 검은 빈 공간 |
| 7 | **유리판 느낌 조작 패널** — 재생·속도·겹 켜고 끄기 | 수수한 막대 |

### 0.2 목표 그림에서 **가져오지 않을 것**

목표 그림은 참고용으로 만든 그림이라 이 앱의 규칙과 어긋나는 것이 섞여 있다.
아래는 **의도적으로 따르지 않는다.**

| 목표 그림 | 왜 안 되는가 | 대신 |
|---|---|---|
| 유치원 교실, 아이 50명과 교사 | 이 앱은 **우리 집**이고 주인공은 **아이 한 명**이다 (v1.0 §1) | 우리 집 한 채, 나 한 명. 성공하면 마지막에 가족이 나온다 (v1.2 §8.6) |
| `TOTAL EVACUEES 42/50`, `PROGRESS 84%` | **점수·등급·순위를 만들지 않는다** (작업지침 §9-9) | 늘어나는 시각과 "지금 어디쯤인지" 한 줄 |
| `SIMULATION CONTROL`, `EXIT`, `SAFE ZONE` 등 영어 | 화면 문구는 한국어다 (작업지침 §8) | 「다시 보기」, 「나가는 곳」, 「안전한 곳」 |
| 붉게 점멸하는 경광등 | **붉은 점멸을 쓰지 않는다** (작업지침 §9-10) | 점멸 없는 붉은 테두리와 글자 |
| `DANGER ZONE` 붉은 큰 글자 | 겁주는 연출이다. 이 앱은 겁주지 않는다 | 「불이 난 곳」 — 담담한 표시 |
| 조작 패널이 두 벌 겹쳐 있음 | 그림 생성 과정의 흔적으로 보인다 | 한 벌만 둔다 |

## 1. 기술 스택 — 작업지침 §9-12 개정

### 1.1 개정 내용

v1.2 §8 은 "라이브러리 없이 WebGL2 를 직접 쓴다"고 했고 작업지침 §9-12 는
"Three.js 를 들이지 않는다"고 했다. **이 조항을 폐지한다.**

목표 그림의 블룸 발광·그림자 맵·앰비언트 오클루전을 손으로 만드는 값이
라이브러리를 들이는 값보다 크다고 판단했다.

| 패키지 | 쓰임 |
|---|---|
| `three` | 3D 렌더링 엔진 |
| `@react-three/fiber` | React 선언형 래퍼 |
| `@react-three/drei` | 카메라 컨트롤·헬퍼 |
| `@react-three/postprocessing` | 블룸 발광 · 앰비언트 오클루전 |
| `three-pathfinding` | (선택) 장애물 회피 경로 |
| `lucide-react` | 조작 패널 아이콘 |
| `tailwindcss` | 조작 패널 유리판 스타일 |

### 1.2 그래도 지키는 것

- **단일 HTML 4MB 상한(NFR-3)은 그대로다.** 실측 결과 전 스택을 넣고 **2.13MB** 다
  (넣기 전 1.03MB). 여유가 줄었으므로 `npm test` 가 매번 잰다.
- **외부 호출 0건(NFR-1)도 그대로다.** 실측 0건을 확인했다. 다음을 **금지**한다.
  - `drei` 의 `<Environment preset=...>` — pmndrs CDN 에서 HDRI 를 받아온다
  - `drei` 의 `<Text>` / troika — 글꼴 파일을 바깥에서 받아온다.
    3D 안의 글자는 **글리프를 직접 삼각형으로 세우거나** HTML 겹판으로 얹는다
  - GLTF·텍스처 파일 — 자산은 코드로 만든다 (FR-11.2 유지)
- **Tailwind 는 `preflight` 를 끈다.** 켜면 전역 초기화가 `kids.css` 를 덮어써 화면이 깨진다.
- **`core/**` 는 그대로 순수하다.** three 는 `ui/replay3d/**` 에서만 부른다.
- **에디터·게임·인쇄는 그대로 SVG 다** (작업지침 §9-3). 3D 는 리플레이에만 있다.
- **WebGL 을 못 쓰면 2D 로 조용히 내려간다** (v1.2 §8.7 유지).

### 1.3 저사양 교실 PC (NFR-13)

목표 그림 수준의 후처리는 무겁다. **화질을 두 단으로 나눈다.**

| 단 | 조건 | 후처리 |
|---|---|---|
| 고 | 기본 | 블룸 + 앰비언트 오클루전 + 그림자 맵 |
| 저 | 아래 중 하나라도 | 후처리 끔 · 그림자 끔 · `dpr` 1 고정 |

저로 내려가는 조건 — `navigator.hardwareConcurrency <= 4`, 또는 처음 2초 평균이 **30fps 미만**.
자동으로 내려가고, 조작 패널에서 **손으로도 바꿀 수 있다**. 화질이 낮아도 기능은 다 된다.

## 2. 장면 (FR-11.4 개정)

### 2.1 구도

기본 시점을 **「위에서」(비스듬히 내려다보는 인형집)** 로 바꾼다.
지금 기본인 1인칭은 목표 그림과 다르고, 처음 보는 아이가 방향을 잃는다.

| 시점 | 이름 | 설명 |
|---|---|---|
| `dollhouse` | **집 전체** | **기본.** 45° 비스듬히 내려다본다. 천장을 걷어 낸 잘린 단면 |
| `follow` | 뒤에서 | 아이 뒤를 따라간다 |
| `first` | 내 눈으로 | 그때 그 눈높이 (v1.2 §8.3 유지 — 낮은 자세면 눈도 내려간다) |

`dollhouse` 에서 끌면 **집을 중심으로 공전**하고 휠로 확대·축소한다.
아래로 파고들지 않게 `pitch` 를 15°~80° 로 묶는다.

### 2.2 빛과 그림자

| 광원 | 값 |
|---|---|
| 반구광 | 하늘 `#cfe3f3` · 땅 `#d8d2c4`, 세기 0.55 |
| 태양(방향광) | 위-앞-왼쪽에서. 그림자 맵 2048. 세기 1.3 |
| 실내 채움광 | 세기 0.25, 그림자 없음 — 잘린 단면 안쪽이 새까매지지 않게 |
| 불빛 | 발화 칸에 주황 점광. **세기를 시간에 따라 흔들지 않는다** (점멸 금지) |

앰비언트 오클루전으로 벽·바닥이 만나는 구석에 그늘을 넣는다. 목표 그림의 포근한 느낌이 여기서 나온다.

### 2.3 빛나는 길 (신규 FR-11.7)

**목표 그림의 핵심이다.** 아이가 그린 경로를 바닥 위에 띠로 깐다.

- 경로 칸을 이어 **폭 0.5칸의 리본**을 만들고 바닥에서 `0.02` 띄운다.
- 색은 안전 녹색(`#22c55e`). 가산 혼합 + 블룸으로 빛난다.
- **진행 방향 화살표**를 일정 간격으로 얹고, 흐르듯 **천천히 움직인다**.
  움직임은 `prefers-reduced-motion` 에서 멈춘다.
- 주 경로는 진하게, 보조 경로는 옅게. 조작 패널에서 **끌 수 있다**.
- 아이가 **실제로 지나온 자리**는 뒤에 옅은 자취로 남는다 — 그린 길과 견줘 보게 한다.

### 2.4 표지와 구역 표시 (신규 FR-11.8)

| 것 | 모양 |
|---|---|
| 나가는 곳 표지 | 출구 칸 위에 녹색 판. 「나가는 곳」과 달리는 사람 기호. `ui/FireSymbols.tsx` 와 같은 모양을 3D 로 세운다 |
| 안전한 곳 | 집 밖 만나는 곳에 녹색 원. 안쪽으로 모이는 화살표 |
| 불이 난 곳 | 발화 칸 둘레에 붉은 테두리와 「불이 난 곳」. **점멸하지 않는다** |
| 연기가 찬 곳 | 옅은 회색 테두리. 숨을 낮추라는 뜻으로 아래쪽에 깔린다 |

3D 안의 글자는 **HTML 겹판**으로 얹는다(`drei` 의 `<Html>` 대신 직접 계산한 화면 좌표에 얹어
글꼴 파일을 받아오지 않는다). 판이 뒤집히거나 세워지지 않게 늘 화면을 마주 본다 —
v1.2 의 "도면 글자가 뒤집히지 않는다" 검증을 3D 에도 그대로 적용한다.

### 2.5 집 밖 (신규 FR-11.9)

검은 빈 공간 대신 **잔디밭·보도·나무 몇 그루**를 둔다. 집이 어디에 서 있는지 보여 준다.
전부 코드로 만든 단순한 형태이고, 저화질 단에서는 나무를 뺀다.

## 3. 조작 패널 (FR-11.5 개정)

목표 그림의 유리판 패널을 따르되 **한국어**로, **계기판 없이** 만든다.

```
┌─────────────────────────────┐
│ ▸ 다시 보기                  │   제목
│ 불이 난 집에서 나오기         │   무슨 장면인지 한 줄
│                             │
│ 지난 시간            21초    │   늘어나는 시각 (점수 아님)
│ ▶  ⏸  ⏭   빠르기  1배       │   재생 · 멈춤 · 한 칸씩 · 속도
│                             │
│ 보이기                       │
│   내가 그린 길        [켬]   │
│   지나온 자취         [켬]   │
│   불과 연기          [켬]    │
│   집 밖 풍경         [켬]    │
│                             │
│ 화질   [높게] [낮게]         │
└─────────────────────────────┘
```

- 좁은 화면(767px 이하)에서는 **아래 띠로 접힌다.** 「보이기」는 시트로 들어간다.
- 누르는 것은 전부 **48×48 이상**이다 (D6 · NFR-10). 유리판이라고 작게 만들지 않는다.
- 유리판 뒤가 비쳐 글자 대비가 떨어지지 않게 **바탕을 충분히 어둡게** 깐다.
  `npm run smoke` 의 본문 대비 4.5:1 전수 검사를 그대로 통과해야 한다.
- 닫기와 `Esc` 는 그대로 둔다 (작업지침 §5).

# 우리집 대피지도 v1.7 변경 명세

## 1. 3D 리플레이 주인공을 선택 캐릭터와 연결한다

### 1.1 바꾸는 까닭

기존 3D 주인공은 상자 몇 개로 만든 공통 형상에 옷 색 하나만 바꿨다. 2D에서 고른 열 명의
머리 모양·피부·옷·소품이 3D로 이어지지 않아, 아이가 자기 캐릭터라고 알아보기 어렵고
게임 리플레이의 완성도도 낮아 보였다.

### 1.2 정본과 생성 방식

- 캐릭터 정본은 기존 `KidSpec` 하나만 쓴다. 2D와 3D에 별도 캐릭터 표를 만들지 않는다.
- 3D 모델은 `ui/replay3d/Avatar3D.tsx`에서 절차적으로 조립한다.
- GLTF·텍스처·외부 글꼴은 추가하지 않는다. 오프라인 동작과 단일 HTML 4MB 상한을 지킨다.
- 선택한 `playerCharacter`를 리플레이까지 그대로 전달한다.

### 1.3 3D로 옮기는 특징

| `KidSpec` 값 | 3D 표현 |
|---|---|
| `skin`, `skinShade` | 얼굴·귀·목·손의 피부와 그늘 |
| `hair`, `hairShade` | 머리 덩어리와 머리결 그늘 |
| `style` | 모자·짧은 머리·곱슬·스포츠 머리·비니·양갈래·단발·땋은 머리·포니테일·머리띠 |
| `top`, `topShade` | 상의와 옆면 그늘 |
| `bottom` | 바지와 다리 |
| `glasses` | 두 안경알과 코받침 |
| `accent` | 모자 장식·머리 장식·가슴 표식 |

모든 캐릭터에는 눈동자 하이라이트·볼·웃는 입·귀·목·손·신발을 넣는다. 얼굴을 평면 그림으로
붙이지 않고 부위별 입체 형상으로 만들어 뒤·옆 시점에서도 납작해 보이지 않게 한다.

### 1.4 움직임과 시점

- 다음 리플레이 칸을 보고 몸의 앞 방향을 정한다.
- 이동 중에는 양팔과 양다리가 반대로 흔들리고 몸이 작게 상하 이동한다.
- 몸 낮추기 상태에서는 키와 자세가 함께 낮아지고 다리가 굽는다.
- 칸 사이 이동과 회전은 보간해 순간이동처럼 튀지 않게 한다.
- 재생을 멈추거나 움직임 줄이기 설정이 켜지면 걷기 동작도 멈춘다.
- 3D 리플레이는 1인칭 시점으로 시작한다. 카메라가 얼굴 안에 들어가지 않도록 전신은 감추고,
  고른 캐릭터의 피부·상의·장식 색을 반영한 두 팔과 손을 화면 아래에 보여 준다.
- 1인칭은 시야각을 넓혀 답답함을 줄이고, 뒤에서 보기는 카메라를 주인공 가까이에 두어 벽 밖으로
  밀려나지 않게 한다.
- 집 전체·뒤에서 보기에서는 주인공을 찾기 쉬운 초록 안내 링과 머리 위 표식을 보인다.
  둘은 점멸하지 않는다.

### 1.5 성능과 검증

- 한 명만 렌더링하고, 저사양 모드에서는 기존처럼 그림자와 후처리를 끈다.
- 연산 테스트는 열 명 모두의 3D 식별 값이 `KidSpec`과 같은지 확인한다.
- 브라우저 테스트는 기본 캐릭터가 아닌 캐릭터를 고른 뒤 3D 리플레이가 같은 id와 머리 모양을
  받는지 확인한다.
- 화면 변경 뒤 `npm run shots`와 실제 3D 캡처로 사람 모양·가림·시점을 눈으로 확인한다.

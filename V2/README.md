# 우리집 대피지도 V2

점과 점을 이어 집을 그리면 칸이 저절로 생긴다. 칸을 「방」과 「지나가는 곳」으로 나누고, 벽에 문을 달고,
칸을 차례로 눌러 나가는 길을 고른다. 그 길로 대피 연습을 하고 3D 로 다시 본다. 1~6학년을 세 단계로 나눈다.

- 주소: <https://leondic1976.github.io/119-Map-Your-Evacuation-Route/> (열면 `/V2/` 로 간다)
- 설계: [`docs/DESIGN.md`](docs/DESIGN.md)
- 음성 대본: [`VOICE-SCRIPT.md`](VOICE-SCRIPT.md)

```bash
npm install
npm run dev      # 개발 서버
npm run verify   # 타입 → 음성 대조 → 웹·오프라인 빌드 → 로직·점검 → 브라우저 시나리오
```

| 검증 | 수 |
|---|---|
| 로직·배포 전 점검 (`npm test`) | 127개 |
| 브라우저 시나리오 (`npm run smoke`) | 38개 — 대장 #155~#156(연습 방향키 판, 집 밖 걷기, 안전 행동 줍기, 칭찬 도장, 발자국), 대장 #148~#150(방향키 판, 내 뒤에서 보는 3D 와 아이 눈높이), 대장 #137~#142(모눈종이, 틈과 트인 칸, 끌어서 긋는 길, 가구 돌리기와 크기, 천천히 자라는 불, 불꽃놀이), 어린이 시험에서 찾은 불편(빈 종이, 막다른 칸, 다시 열기, 창 크기, 지도 글자, 3D 끝 장면), 저장본 없음과 도면만 저장, 점 개수, 아파트 모양과 가구, 집 밖 네 방향, 첫 화면 움직임과 배치와 겹침, 이어 가기 안내와 처음부터 다시 하기, 세 학년 단계 끝까지, 비스듬한 벽과 세모 칸 가구, 지도 크게 보기, 오프라인 HTML, 인터넷 끊김, 이전 판 전환, 사용법과 화살표, 처음 화면으로, 설정, 막지 않기, 음성, 작은 화면 |
